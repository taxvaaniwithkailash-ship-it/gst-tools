GST set-off engine for GSTR-3B (Table 6.1)

A small, dependency-free JavaScript implementation of the order in which input tax credit pays output tax under the CGST law, published so that accountants and developers can check, reuse and improve it.

Rules the engine applies

StepRuleLegal basis
1IGST credit first against IGSTSection 49(5)(a), Rule 88A
2Balance IGST credit against CGST and SGST, in any order and proportion; it must be fully used before CGST or SGST creditSections 49(5)(a), 49A, Rule 88A
3CGST credit against CGST, SGST credit against SGST; never CGST against SGST or the reverseSection 49(5)(b) to (d)
4Remaining CGST or SGST credit against IGST, only after IGST credit is exhaustedSection 49(5)(b),(c), Rule 88A
5Compensation cess credit only against cessCompensation Cess Act, Section 11
-Reverse charge tax paid in cashSection 49(4) read with Section 2(82)
-Where Rule 86B applies, ITC may discharge at most 99% of output taxRule 86B
-Interest at 18% a year on tax paid in cash after the due dateSection 50

Use it in your own code

const gstSetoff = require('./gst-setoff.js');   // or <script src="gst-setoff.js"> then window.gstSetoff
const r = gstSetoff({
  liab: { I: 100000, C: 60000, S: 60000, X: 0 },   // forward-charge output tax
  rcm:  { I: 0,      C: 2000,  S: 2000,  X: 0 },   // reverse charge tax (cash only)
  itc:  { I: 130000, C: 25000, S: 45000, X: 0 },   // ITC available
  r86b: false, igstOrder: 'CS', days: 0
});
console.log(r.cashTotal);   // 24000
